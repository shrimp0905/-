# SECRET TALK V5 — EPHEMERAL CHAT

핵심 목표는 **채팅 기록을 저장하지 않는 것**입니다.

## 기록 방지 구조
- 서버에 채팅 DB가 없습니다.
- WebSocket 서버는 방 입장과 WebRTC signaling만 중계합니다.
- 실제 채팅 텍스트와 파일 바이트는 WebRTC DataChannel을 통해 브라우저 간 전달됩니다.
- 서버는 채팅 메시지/파일 내용을 저장하지 않습니다.
- 브라우저 localStorage에는 채팅 기록을 저장하지 않습니다.
- 페이지를 새로고침하면 화면의 채팅이 사라집니다.
- 방의 마지막 사용자가 나가면 서버의 방 메모리도 삭제됩니다.
- HTTP 응답에 `Cache-Control: no-store`를 적용했습니다.

## 포함 기능
- 닉네임
- 방 생성/참가/나가기
- 방 비밀번호
- 방 내 닉네임 중복 방지
- 실시간 1:1 P2P 채팅
- P2P 파일 전송/다운로드
- 상태메시지
- 음식 추천 및 친구에게 전송
- 모바일 반응형 UI

## 중요한 한계
'기록이 남지 않는다'는 것은 **이 앱이 서버/앱 자체에서 대화를 저장하지 않는다는 의미**입니다.
상대방이 메시지를 캡처하거나 복사하거나 파일을 저장하는 것까지 웹앱이 막을 수는 없습니다.
또한 WebRTC 연결에는 브라우저/OS/네트워크 수준의 외부 로그가 존재할 가능성이 있습니다.

실서비스 공개 전에는 HTTPS/WSS, TURN 서버, 파일 크기 제한, rate limit, abuse 방지, 보안 감사 등을 추가하세요.
